# Stellar-Analysis
# Stellar Data Analysis using MATLAB

This repository contains MATLAB Live Scripts and data files for analyzing stellar data, including redshift and star comparison studies. The project demonstrates basic astronomical data processing and visualization in MATLAB.

## Contents

- `Red shift.mlx`: A MATLAB Live Script that demonstrates how to calculate and analyze the redshift of celestial objects.
- `Comparing stars.mlx`: A MATLAB Live Script that compares properties of different stars using a dataset.
- `stellar_data.mat`: A `.mat` file containing stellar data used in the scripts.

## Features

- Redshift calculation and interpretation
- Visualization of spectral shifts
- Star classification and comparison using luminosity, temperature, and other parameters
- Data handling using MATLAB structures and arrays
